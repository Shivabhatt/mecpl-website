name: MECPL shared typography
description: The user-selected typography reference between the MECPL Home and About pages.
---

Use Montserrat as the only font family throughout the MECPL website. The Home page remains the typography reference for corresponding About-page roles; adapt sizes, weights, and line-height by semantic role rather than forcing every text element to one size.

**Why:** The user asked to use the Home page's typography on About while retaining visual hierarchy, and later specified that the overall website should use Montserrat.

**How to apply:** When changing About typography, mirror Home's hero, section heading, label, body, card, and stat roles with matching responsive behavior. Keep only role-specific exceptions where the Home page has no equivalent.
