name: MECPL shared typography
description: The user-selected typography reference between the MECPL Home and About pages.
---

For MECPL, Home page typography is the reference for corresponding About-page roles. Keep Montserrat as the only font family and adapt sizes, weights, and line-height by semantic role rather than forcing every text element to one size.

**Why:** The user explicitly asked to use the Home page's typography on About while retaining visual hierarchy.

**How to apply:** When changing About typography, mirror Home's hero, section heading, label, body, card, and stat roles with matching responsive behavior. Keep only role-specific exceptions where the Home page has no equivalent.
