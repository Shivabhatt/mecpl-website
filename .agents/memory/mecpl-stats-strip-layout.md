---
name: MECPL statistics-strip spacing
description: The user's full-width, 120px desktop-side-padding requirement for certification and completed-project metrics.
---

The Certifications assurance numbers and Completed Projects delivery metrics should use the full available width with exactly 120px left and right padding on desktop. Use smaller spacing on mobile.

**Why:** The user explicitly requested this for the Certifications statistics, then requested the same spacing for Completed Projects. A narrow centered maximum-width container does not match their intent on wide screens.

**How to apply:** Keep the metrics grid full width within its padded section. Scope this rule to those statistics strips; do not change other page sections or the shared footer.
