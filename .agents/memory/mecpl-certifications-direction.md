description: Certification-only scope and the certificate viewer reference.

The Certifications page should contain certifications only, not awards. Keep the common footer. Clicking a certification should open its original certificate in a light-background popup with previous/next controls, following the supplied certificate-viewer reference.

Use the supplied construction image as the banner background, center the existing banner text, and match the other full-screen banners' height. Include certification-related content on a charcoal background below the banner.

Use the supplied compact statistics-strip reference for the charcoal assurance area. Follow the shared [statistics-strip spacing](mecpl-stats-strip-layout.md) requirement.

Keep the safety helmet visibly recognizable when cropping the banner for desktop and mobile.

Give each certification a visible, standard-specific logo treatment and a distinctive visual presentation, not just plain text-only cards.

Red accent lines should belong to individual standards with visible gaps between entries, not a continuous rail with circular markers.

Avoid generic card-only layouts: the user wants the whole Certifications page to look beautiful and designed like a WordPress website. Do not reintroduce the standalone closing sales CTA.

The newer CTA reference is separate from that removed sales section: a centered charcoal block with a red “View Awards” button, above the common footer on the Certifications page.

**Why:** The user explicitly requested a certification-only redesign and supplied separate closing-section, certificate-popup, and banner references. They rejected the plain cards as uncreative, requested logos for the particular certifications, and pointed out that the safety helmet was not properly visible in the banner. They removed the continuous red rail, then requested separate reference-style lines with space between standards. They also requested removal of the closing sales CTA and a more designed appearance across the whole page, followed by a new reference-based Awards CTA whose placement they clarified should be above the footer. Their assurance reference calls for a statistics strip using the full width with only 120px padding at either desktop edge.

**How to apply:** Keep awards in the Awards experience; verify certification documents against supplied source material rather than treating every recognition or appreciation letter as a certification.
